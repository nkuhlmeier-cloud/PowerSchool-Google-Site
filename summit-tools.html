WHAT IS SUMMIT TOOLS?

Summit's own shelf in the left menu

Summit Tools is the first thing in the left menu of PowerSchool SIS — the wrench. The pages built just for Summit live here, so you don't have to hunt through PowerSchool's menus for them.

  1. 1
    Hover over it (or click it) and the list slides out to the right.
  2. 2
    Click the item you need. The next steps go through the menu in order.
  3. 3
    A few items work on one student — search the student first, then open the item.
GOOD TO KNOW

A few things about this menu

GOOD TO KNOW
👁️Admin side only. Summit Tools lives in PowerSchool SIS, not in PowerTeacher — teachers get the same things as buttons on their Start Page (Print Student Schedules, View Student ICSP, View Student IEP).
🔍Pick the student first. If an item opens with no student on it (or asks you to select one), search the student, then open the item again.
🔒Missing an item a colleague has? That's permissions, not a glitch — reach out.
✨New Summit pages land here first. When something new is built for Summit, this menu is where it goes — and this page gets a new line.
