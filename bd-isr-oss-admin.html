PART 1  —  ENTER BD, ISR OR OSS
BDcounts as Present
ISRcounts as Present
OSScounts as Absent
1

Find the student

▾
On the Start Page, type the student's last name in the search bar and press Enter. Click the name.
📷 picture 1 below
2

Click Attendance, then Modify Attendance

▾
Left-hand menu → Attendance → Modify Attendance in the menu that pops out.
📷 picture 2 below
3

Choose the code and add a Comment

▾
Under Current attendance code pick BD (Bedrest), ISR (In School Restriction) or OSS (Out of School Suspension). Click the little note button in the class box to type the reason as a Comment — the comment is how the “why” travels with the code.
📷 picture 3 below
4

Set All under the day, then Submit

▾
Click Set All under today's date (or click single periods), then scroll to the bottom and click Submit.
📷 picture 3 below
PART 2  —  END-OF-DAY PASS
Goal: nobody who is actually on grounds is still marked absent when the day closes.
5

Run the Absentee Report

▾
Left nav Attendance → under Attendance Reports click Absentee Report. Set Attendance Mode Meeting, All students, code A (Absent), Date to Scan today, then Submit at the bottom. The list shows every student still marked absent.
📷 pictures 4 and 5 below
6

Fix the students who are here

▾
For each student on the list who is on grounds: open the student → Modify Attendance → code CG (Cut, on Grounds) or CC (Cut, in Cottage) → Set All → Submit. Many students? Select them on the Start Page and use Mass Update Attendance.
📷 picture 3 below
7

Check that every teacher submitted

▾
Left nav Attendance → Teacher Attendance Submission Status → choose Incomplete Attendance → Submit. That is the list of classes with no attendance yet. Nudge those teachers — unsubmitted classes show as blanks, not absences.
📷 pictures 4 and 6 below
GOOD TO KNOW
✅BD and ISR count as PRESENT. OSS counts as ABSENT.
📝Always add a Comment. The code says what happened; the comment says why.
📍CG = Cut, on Grounds · CC = Cut, in Cottage. Use them at the end-of-day pass, not as a first code.
⛔Skip “Change Meeting Attendance” — security error. Use Modify Attendance.
